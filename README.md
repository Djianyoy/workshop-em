# Sistem Raport Evaluasi Fungsionaris - Frontend

Project ini dibangun menggunakan Next.js (App Router), TypeScript, dan Tailwind CSS.

## Struktur Folder Utama
- `/app` : Berisi sistem routing berbasis file.
- `/components` : Komponen UI reusable.
- `/libs` : Konfigurasi library eksternal (termasuk store state management).
- `/schemas` : Skema validasi input form menggunakan Zod.
